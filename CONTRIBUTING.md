# Contributing to LibrePen

Thanks for helping improve LibrePen. Contributions should be focused, easy to review, and consistent with the project's existing design and architecture.

## Development workflow

1. Fork the repository.
2. Create a branch for your change.
3. Install dependencies with npm install.
4. Start the development server with npm run dev.
5. Make a focused change and test the affected desktop and mobile behavior.
6. Run npm run lint.
7. Run npm run build.
8. Open a pull request.

Issues and pull requests should clearly explain the problem, the proposed change, and any relevant testing. Screenshots are helpful when a change affects the interface.
